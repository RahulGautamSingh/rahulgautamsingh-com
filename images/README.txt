SWAP
  Each figure currently holds a hand-drawn SVG. To use a meme instead, replace
  everything between <figure> and </figure> with:

      <img src="../images/meme-1.png" alt="short description of the joke">
      <figcaption>your caption</figcaption>

  Keep the alt text. It is what a screen reader and Google see.
